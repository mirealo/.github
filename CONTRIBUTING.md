# Contributing

Thank you for helping improve a Mirealo project.

## Before contributing

1. Read the target repository's README, license, and local contribution guide.
2. Search existing issues and pull requests to avoid duplicates.
3. Open an issue before substantial work unless maintainers have already
   approved the change.
4. Never include secrets, personal data, proprietary material, or unrelated
   generated files.

## Pull requests

- Keep each pull request focused on one independently reviewable change.
- Explain the problem, the chosen approach, risks, and validation performed.
- Add or update tests and documentation when behavior changes.
- Use clear commit messages and keep the branch current with its target.
- Resolve review conversations before requesting final review.
- Confirm that you have the right to contribute the submitted material under
  the repository's license.

Maintainers may close changes that are unsafe, out of scope, insufficiently
tested, or inconsistent with the project's direction.
